## UAPlay 0.5.2 — Nintendo Switch

- UAPlay перевіряє релізи GitHub у фоновому режимі після запуску. Якщо є нова версія, можна переглянути **Деталі** або вибрати **Встановити**. Після встановлення запустіть UAPlay знову.
- У Movy під час перемотування на екрані залишається останній кадр. Окремий екран перемотування прибрано.
- Джерело HydraHD видалено.

Для переходу на 0.5.2 замініть `sdmc:/switch/UAPlay.nro` вручну. Налаштування, вибране, історія й завантаження зберігаються на SD-карті. Наявний NSP-форвардер продовжує запускати NRO за тим самим шляхом.
