# UAPlay — відеокаталог для Nintendo Switch

**Українська** | [English](README.en.md)

**UAPlay** — нативний homebrew-застосунок для Nintendo Switch з україномовним каталогом фільмів, серіалів, мультфільмів та аніме. Він використовує метадані [TMDB](https://www.themoviedb.org/) і шукає доступні відеопотоки в окремих сторонніх джерелах.

Застосунок написаний на C із використанням **libnx, SDL2 та libmpv**. Це не вебсторінка у браузері: для інтерфейсу й відтворення не потрібні Chromium, WebKit або TorrServer.

> **Поточний випуск: [UAPlay 0.5.1](https://github.com/Small182/UAPlay-nx/releases/tag/UAPlay_0.5.1).** Проєкт активно розвивається; доступність відео залежить від сторонніх сервісів. Успішна збірка не гарантує відтворення кожного відео на консолі.

## Завантаження та встановлення

Завантажити обидва файли можна з [релізу 0.5.1](https://github.com/Small182/UAPlay-nx/releases/tag/UAPlay_0.5.1). Попередні випуски доступні в [історії релізів](https://github.com/Small182/UAPlay-nx/releases).

| Файл | Призначення |
|---|---|
| `UAPlay.nro` | Основний застосунок. **Обов'язковий** для запуску. |
| `UAPlay.nsp` | Необов'язковий ярлик для запуску UAPlay з головного меню Switch. |

1. На SD-карті створіть папку `switch`, якщо її ще немає.
2. Скопіюйте **`UAPlay.nro`** точно за шляхом **`sdmc:/switch/UAPlay.nro`**.
3. Запустіть Homebrew Menu в режимі повного застосунку (наприклад, утримуючи **R** під час запуску гри) та виберіть UAPlay.
4. **За бажанням:** установіть `UAPlay.nsp` за допомогою сумісного інсталятора homebrew, щоб запускати UAPlay з головного меню.

**Важливо:** `UAPlay.nsp` — форвардер, а не самостійна копія застосунку. Якщо видалити або перемістити `UAPlay.nro`, ярлик перестане працювати. Встановлення неофіційних NSP вимагає відповідно налаштованої CFW та пов'язане з ризиками для системи й доступу до сервісів Nintendo.

Під час оновлення **замініть тільки `UAPlay.nro`**. Не видаляйте папки з даними користувача. NSP зазвичай не потрібно перевстановлювати, якщо шлях запуску та ярлик не змінювалися.

## Можливості

- **Каталог українською:** фільми, серіали, мультфільми, мультсеріали, аніме та жанрові добірки.
- **Головна сторінка:** горизонтальні добірки з постерами, рейтингами та кнопкою «Усі» для відкриття повного списку.
- **Пошук:** назви з TMDB, екранна клавіатура Switch, фільтрація нерелевантних результатів.
- **Інформація про тайтл:** опис, рік, жанри й доступні метадані; вибір джерела перед пошуком відео.
- **Вибране та історія:** окремі списки «На майбутнє» й «Історія», збереження позиції перегляду та можливість очищення історії без видалення вибраного.
- **Серіали й аніме:** вибір сезонів і серій, коли джерело надає відповідні дані; підтримка переходу до наступної серії.
- **Завантаження на SD-карту:** **Y** у списку джерел фільму або серій; вкладка **«Завантажені»** у «Вибраному», прогрес, повторна спроба, видалення й офлайн-відтворення підтримуваних потоків.
- **Батарея Switch:** індикатор заряду в каталозі та на панелі плеєра, без зайвих позначок.
- **Плеєр libmpv:** пауза, перемотування, регулювання гучності, вибір доступних аудіодоріжок, озвучок і субтитрів.
- **Налаштування відео:** швидкість, гучність, розмір субтитрів і пресети якості HLS (Авто / 360p / 480p / 720p / 1080p).
- **Керування:** Joy-Con/Pro Controller та сенсорний екран.
- **Теми оформлення:** світла й темна; вибір кольорового акценту.
- **Японський шрифт:** підтримка японських символів у назвах аніме.

Каталог застосовує фільтрацію країн виробництва за метаданими TMDB, зокрема виключає записи з `RU`. Якщо країну неможливо перевірити, деякі результати можуть бути приховані.

## Джерела відео

Вибір джерела відбувається **до** пошуку відео. У меню **Налаштування → Джерела** натисніть **A** або торкніться рядка, щоб увімкнути чи вимкнути джерело. Вимкнені джерела приховано зі списку вибору, і UAPlay не надсилає до них пошукових запитів. Вибір зберігається на SD-карті.

У поточній бета-версії доступні:

| Джерело | Примітка |
|---|---|
| UAFlix | Фільми та серіали; підтримка частини сторінок із серіями. |
| UASerials | Пошук україномовного контенту. |
| Eneyida | Тестова інтеграція. |
| UAFilm | Тестова інтеграція. |
| UAKino | Тестовий пошук; для частини запитів використовується альтернативне дзеркало. |
| Mikai | Аніме; доступність відео залежить від хостингу. |
| AnimeON | Аніме; окремі плеєри можуть повертати **HTTP 403**. |

**Не кожен знайдений результат можна відтворити.** Деякі сайти змінюють структуру сторінок, вимагають авторизації, обмежують доступ за регіоном або блокують прямі запити. UAPlay не обходить такі обмеження. 

## Керування

Позначення кнопок відповідають **Nintendo Switch**, а не Xbox-контролеру.

| Де | Керування |
|---|---|
| Каталог | **Хрестовина / стік** — переміщення; **A** — відкрити; **B** — назад; **L/R** — перемикання основних розділів. |
| Пошук і меню | **X** — пошук; **Y** — оновити каталог; **− (Minus)** — налаштування; **+ (Plus)** — вихід. |
| Добірка постерів | **↑** із крайнього правого постера — перехід на кнопку **«Усі»**. |
| Категорії | **→** з останньої вкладки («Документальне» / «Аніме») — **«Усі»**; **←** з «Усі» — назад до вкладки ліворуч. |
| Картка тайтлу | **A** — вибрати джерело / дивитися; **X** — додати до вибраного; **Y** — позначити переглянутим. |
| Джерела, сезони, серії | **↑/↓** — вибрати; **A** — підтвердити; **B** — повернутися. Працює дотик. |
| Плеєр | **A** — пауза; **←/→** — перемотування на 10 с; **R + ←/→** — на 60 с; **↑/↓** — гучність; **B** — закрити плеєр. |
| Доріжки й відео | **X** — субтитри; **Y** — аудіо/озвучки; **− (Minus)** — параметри відео. |

Горизонтальні свайпи гортають ряди постерів. На головній вертикальні свайпи над постерами перемикають добірки. Вертикальні свайпи також гортають сітки постерів і довгі списки джерел, сезонів, серій, доріжок та завантажень. Короткий дотик відкриває постер або пункт списку.

Сенсорний плеєр має панель керування, смугу перемотування й повзунок гучності. Панель автоматично ховається після кількох секунд бездіяльності.

## Дані користувача та оновлення

Вибране, історія й позиції перегляду зберігаються **локально на SD-карті**, не у файлі NRO. Основний файл бібліотеки: `sdmc:/switch/uaflix/library.tsv` (історичний шлях, збережений для сумісності з попередніми версіями).

Оновлення через заміну `UAPlay.nro` **не повинно скидати вибране**. Для резервного копіювання збережіть папку `sdmc:/switch/uaflix/` перед форматуванням SD-карти або перевстановленням системи.

## Збірка з вихідного коду

Проєкт призначений для Nintendo Switch із devkitPro/devkitA64 та бібліотеками `libnx`, `SDL2`, `SDL2_ttf`, `SDL2_image`, `libmpv`, `libcurl` і мережевою збіркою FFmpeg для Switch.

Найпростіший спосіб отримати готовий NRO — [GitHub Actions](https://github.com/Small182/UAPlay-nx/actions/workflows/build.yml). Воркфлоу збирає `UAPlay.nro` у контейнері devkitPro та публікує його як артефакт.

Локально в налаштованому devkitPro-середовищі:

```sh
make -j2
```

Для офіційної релізної збірки ключ TMDB передається з GitHub Actions Secret `TMDB_API_KEY` під час компіляції. **Ключ не зберігається в публічному репозиторії.** Локальна збірка без цього налаштування може потребувати ключа в `sdmc:/switch/uaplay/tmdb.key`. Не додавайте власні API-ключі в коміти чи логи.

Деякі тести парсерів і каталогу розміщені в папці [`tests/`](tests/). Вони не замінюють перевірку на реальній консолі.

- Підтримка конкретного відео, сезону, озвучки та субтитрів залежить від того, що надає джерело і що може прочитати libmpv.
